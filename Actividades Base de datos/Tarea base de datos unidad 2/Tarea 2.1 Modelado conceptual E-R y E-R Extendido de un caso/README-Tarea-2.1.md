## 📝 Descripción del Contenido

1. **Diseño Entidad-Relación (E-R)**: Definición de entidades principales (Pacientes, Médicos, Citas, Historiales), atributos clave y cardinalidad entre relaciones.
2. **Modelo E-R Extendido**: Incorporación de conceptos avanzados como jerarquías de especialización/generalización, entidades débiles y atributos compuestos.
3. **Caso Práctico**: Solución integral orientada al modelado de datos de una clínica médica.
