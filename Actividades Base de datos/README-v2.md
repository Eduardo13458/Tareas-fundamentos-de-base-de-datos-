## 📌 Recomendaciones de Uso en GitHub

1. **Espacios en enlaces:** En Markdown, los espacios en los nombres de carpeta se reemplazan por `%20` (por ejemplo, `Actividades%20unidad%201/Actividad%201.1/`).
2. **Nombres de carpetas:** Si las subcarpetas tienen nombres diferentes (por ejemplo `Actividad_1_1` o `Práctica 1`), simplemente ajusta el texto dentro de los paréntesis del enlace `[Texto](./Ruta/)`.
