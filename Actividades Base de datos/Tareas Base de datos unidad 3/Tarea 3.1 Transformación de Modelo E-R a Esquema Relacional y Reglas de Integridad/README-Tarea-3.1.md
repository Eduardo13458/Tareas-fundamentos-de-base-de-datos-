## 📝 Descripción del Contenido

1. **Transformación E-R a Esquema Relacional**: Mapeo paso a paso de entidades, atributos simples y compuestos a tablas relacionales.
2. **Reglas de Integridad**: Definición rigurosa de claves primarias (PK), claves foráneas (FK), restricciones de unicidad, nulidad y de dominio.
3. **Mapeo de Relaciones N:M y 1:N**: Creación de tablas intermedias y propagación de llaves para garantizar la consistencia relacional.
